# คู่มือการใช้งาน Stock Monitor (โหมดฟรี: GitHub Pages + LINE)

ระบบนี้วิเคราะห์หุ้นและ ETF สหรัฐฯ ที่คุณเลือกทุกวันทำการหลังตลาดปิด แล้วส่ง **สรุปแผนสำหรับวันทำการถัดไป** มาทาง LINE วันละ 1 ข้อความ พร้อมหน้าเว็บสำหรับดูรายละเอียด

> ⚠️ ระบบเป็นเครื่องมือช่วยวิเคราะห์ทางเทคนิคและพื้นฐานจากข้อมูลราคาปิด (end-of-day) **ไม่ใช่คำแนะนำการลงทุน** และไม่ซื้อขายแทนคุณ ควรใช้ประกอบการตัดสินใจร่วมกับข้อมูลอื่นเสมอ

---

## 1. ระบบทำงานเมื่อไหร่

| รอบ | เวลา UTC | เวลาไทย | หน้าที่ |
|---|---|---|---|
| รอบหลัก | 22:15 จันทร์–ศุกร์ | **05:15** อังคาร–เสาร์ | วิเคราะห์และส่ง LINE |
| รอบสำรอง | 01:30 อังคาร–เสาร์ | **08:30** อังคาร–เสาร์ | ส่งให้ถ้ารอบหลักยังไม่ได้ส่ง (เช่น Yahoo ปล่อยข้อมูลช้า) |

- ตลาดหุ้นสหรัฐฯ เปิด **21:30 น.** เวลาไทย (ช่วงพ.ย.–มี.ค.) หรือ **20:30 น.** (ช่วงมี.ค.–พ.ย.) จึงมีเวลาทั้งวันในการอ่านแผนก่อนตลาดเปิด
- **วันหยุดตลาดสหรัฐฯ** ระบบข้ามให้อัตโนมัติ ไม่มีข้อความ
- **ส่งแค่วันละ 1 ข้อความเสมอ** ต่อให้รันหลายรอบก็ไม่ส่งซ้ำ
- GitHub อาจเริ่มรันช้ากว่าเวลาที่ตั้งไว้ได้ (บางครั้งเป็นชั่วโมง) ซึ่งเป็นเรื่องปกติของ GitHub

## 2. การอ่านข้อความ LINE

ตัวอย่าง (วิธีอ่าน indicator แต่ละตัว ดูที่ [INDICATOR_GUIDE_TH.md](INDICATOR_GUIDE_TH.md)):

```
📊 Plan for 2026-11-09
Based on close 2026-11-06 · END_OF_DAY

SPY close              $766.81 +1.65%

🟢 Consider accumulating
 • AAPL $349.51 (+0.85%) · score 85
     RSI 45.2 · SMA200 +2.1% · 52W high -6.40% · Weekly Bullish
🔴 Review / reduce risk
 • GOOGL $288.93 (-1.20%) · score 40
     RSI 30.2 · SMA200 -15.0% · 52W high -29.29% · Weekly Bearish · Trend Weakening
🔁 Signal changes
 • META: BULLISH → NEUTRAL
✅ Hold — trend intact
 • V, MSFT, JNJ, JPM, VTI
👀 Watch
 • NVDA, AMZN, QQQ
[ Open Dashboard ]
```

| หัวข้อ | ความหมาย | สิ่งที่อาจพิจารณา |
|---|---|---|
| **Plan for (วันที่)** | วันทำการถัดไปที่แผนนี้ใช้ | — |
| **Based on close** | ใช้ราคาปิดของวันไหน | ข้อมูลเป็นราคาปิด ไม่ใช่ real-time |
| **SPY close** | ภาพรวมตลาด (S&P 500 ETF) | ดูว่าตลาดโดยรวมขึ้นหรือลง |
| 🟢 **Consider accumulating** | ยังเป็นขาขึ้นระยะยาว แต่ราคาย่อตัวลงมาใกล้แนวรับ | อาจพิจารณาทยอยซื้อเพิ่ม (DCA) |
| 🔴 **Review / reduce risk** | แนวโน้มอ่อนลงหรือเป็นขาลง | ทบทวนว่าควรถือต่อ ลดสัดส่วน หรือชะลอการซื้อเพิ่ม |
| 🔁 **Signal changes** | สัญญาณเปลี่ยนจากวันก่อน | ดูรายละเอียดบนเว็บว่าเปลี่ยนเพราะอะไร |
| ✅ **Hold — trend intact** | แนวโน้มระยะยาวยังดี | ถือต่อได้ตามแผน |
| 👀 **Watch** | กลาง ๆ ยังไม่ชัดเจน | เฝ้าดู ยังไม่ต้องทำอะไร |
| ⚠️ **Data issues** | ข้อมูลหุ้นตัวนั้นไม่ครบหรือไม่อัปเดต | ระบบไม่ให้สัญญาณกับข้อมูลที่ไม่สมบูรณ์ ลองดูวันถัดไป |

กดปุ่ม **Open Dashboard** เพื่อเปิดหน้าเว็บดูรายละเอียด

## 3. การใช้หน้าเว็บ (Dashboard)

เปิดได้จากปุ่มใน LINE หรือที่ `https://<ชื่อ GitHub ของคุณ>.github.io/<ชื่อ repo>/`

**การ์ดด้านบน:** ราคาปิดของ SPY, จำนวนหุ้นที่ "ควรพิจารณาสะสม", จำนวนที่ "ควรทบทวน" และจำนวนหุ้นที่สัญญาณเปลี่ยน

**ตาราง (เรียงตามคะแนนจากมากไปน้อย):**

| คอลัมน์ | ความหมาย |
|---|---|
| Close / Day | ราคาปิดล่าสุด และ % เปลี่ยนแปลงจากวันก่อน |
| Action for next session | สิ่งที่ระบบแนะนำให้พิจารณาในวันทำการถัดไป |
| Signal | สัญญาณระยะยาว (ดูหัวข้อ 4) |
| Score | คะแนนการลงทุนระยะยาว 0–100 (มี `*` = ข้อมูลไม่ครบ ใช้ด้วยความระมัดระวัง) |
| RSI | โมเมนตัม 0–100 (เกิน 70 = ร้อนแรงเกินไป, 40–50 = โซนสะสมในขาขึ้น) |
| 1Y | ผลตอบแทน 1 ปี รวมเงินปันผล |
| Trend (130d) | กราฟราคาย่อประมาณ 6 เดือน |

**คลิกที่แถวหุ้น** เพื่อดู:
- **Why:** เงื่อนไขที่ทำให้ได้สัญญาณนี้
- **Score:** คะแนนแต่ละด้านพร้อมจุดแข็งและจุดอ่อน
- SMA 50/200, ระยะห่างจากจุดสูงสุด 52 สัปดาห์, ผลตอบแทนเทียบ SPY, แนวโน้มรายสัปดาห์ และ flag เตือน

## 4. ความหมายของสัญญาณและคะแนน

### สัญญาณ (Signal)

| สัญญาณ | เงื่อนไขโดยย่อ | Action ที่แสดง |
|---|---|---|
| **ACCUMULATION WATCH** | ขาขึ้นระยะยาว + RSI 40–50 + ราคาใกล้ SMA 50 หรือ SMA 200 (−1.5% ถึง +3%) + โมเมนตัมเริ่มดีขึ้นหรือแรงขายลดลง | Consider accumulating |
| **STRONG LONG TERM TREND** | คะแนน 80–100 | Hold — trend strong |
| **BULLISH** | คะแนน 65–79 | Hold — trend intact |
| **NEUTRAL** | คะแนน 50–64 | Watch |
| **WEAKENING** | คะแนน 35–49 | Review position |
| **BEARISH** | คะแนน 0–34 | Avoid / review |

**Flag เพิ่มเติม:**
- **TREND_WEAKENING:** ราคาหลุด SMA 200 ร่วมกับสัญญาณอ่อนแออื่น เช่นปิดรายสัปดาห์ต่ำกว่า SMA 40 หรือ SMA 200 เริ่มชี้ลง Action จะเปลี่ยนเป็น **Review position** แม้คะแนนยังไม่ต่ำ
- **OVERBOUGHT:** RSI สูงกว่า 70 หรือราคาวิ่งห่างจากเส้นค่าเฉลี่ยมาก Action จะมี **· don't chase** ต่อท้าย (ไม่ควรไล่ราคา) แต่**ไม่ใช่สัญญาณขาย**

### คะแนนการลงทุนระยะยาว (0–100)

| ด้าน | น้ำหนัก | ดูจากอะไร |
|---|---|---|
| Trend Strength | 30% | ราคา vs SMA 200, SMA 50 vs SMA 200, ทิศทาง SMA 200, แนวโน้มรายสัปดาห์, ADX |
| Momentum | 20% | RSI, MACD, ผลตอบแทน 6 เดือน, ROC |
| Fundamental Quality | 25% | การเติบโตของรายได้, อัตรากำไร, ROE, กระแสเงินสดอิสระ (จาก SEC) |
| Financial Health | 15% | หนี้ต่อทุน, current ratio, ความสามารถจ่ายดอกเบี้ย, กระแสเงินสดเป็นบวก |
| Relative Performance | 10% | ผลตอบแทน 6 เดือนและ 1 ปี เทียบกับ SPY |

- **ข้อมูลที่ขาดจะไม่ถูกนับเป็นศูนย์** ระบบคิดคะแนนจากส่วนที่มีข้อมูล แล้วแสดง coverage ว่าครอบคลุมกี่ %
- **ETF** (เช่น QQQ, VTI) ไม่มีงบการเงิน จึงมี coverage ประมาณ 60% และมีเครื่องหมาย `*` ซึ่งเป็นเรื่องปกติ
- **คะแนนสูงไม่ได้รับประกันผลตอบแทนในอนาคต** เป็นแค่การสรุปสภาพปัจจุบันของหุ้น

## 5. ตัวอย่างการใช้งานประจำวัน

1. **ตอนเช้า (หลัง 05:15 น.):** อ่านข้อความ LINE
2. **หุ้นในกลุ่ม 🟢:** ถ้าเป็นหุ้นที่มีแผนสะสมอยู่แล้ว ให้กดดูรายละเอียดบนเว็บว่าเงื่อนไขครบแค่ไหน แล้วพิจารณาตั้งคำสั่งซื้อก่อนตลาดเปิด
3. **หุ้นในกลุ่ม 🔴 ที่ถืออยู่:** อ่านเหตุผลในหัวข้อ "Why" แล้วตัดสินใจว่าจะถือต่อ ลดสัดส่วน หรือหยุดซื้อเพิ่ม
4. **หุ้นในกลุ่ม 🔁:** ดูว่าสัญญาณเปลี่ยนไปทางดีขึ้นหรือแย่ลง
5. **วันที่ไม่มีอะไรเปลี่ยน:** ไม่ต้องทำอะไร ระบบนี้ออกแบบมาสำหรับการลงทุนระยะยาว ไม่ใช่การเทรดรายวัน

**สำหรับ DCA:** ซื้อตามรอบปกติของคุณ แล้วอาจใช้สัญญาณช่วยปรับเล็กน้อย เช่น ซื้อมากขึ้นเมื่ออยู่ในกลุ่ม 🟢 หรือชะลอเมื่อมี "don't chase" แต่ไม่ควรหยุด DCA ทั้งหมดเพราะสัญญาณวันเดียว

## 6. การเพิ่มหรือลบหุ้น

แก้ไฟล์ **`snapshot.config.json`** ใน repo (บน GitHub กดที่ไฟล์ → ไอคอนดินสอ ✏️ → แก้ → **Commit changes**)

```json
{
  "symbols": ["AAPL", "MSFT", "NVDA", "VOO"],
  "benchmark": "SPY",
  "asset_types": { "VOO": "ETF" },
  "names": { "AAPL": "Apple", "MSFT": "Microsoft", "NVDA": "NVIDIA", "VOO": "Vanguard S&P 500" },
  "fundamentals": true,
  "site_url": ""
}
```

| ช่อง | วิธีใช้ |
|---|---|
| `symbols` | รายชื่อหุ้นที่ต้องการติดตาม ใช้ชื่อย่อแบบ Yahoo Finance หุ้นที่มี class ใช้ขีด เช่น `BRK-B` |
| `asset_types` | **ใส่ ETF ทุกตัวที่นี่** เป็น `"ETF"` ระบบจะได้ไม่ไปขอข้อมูลงบการเงินจาก SEC (หุ้นที่ไม่ได้ระบุถือเป็นหุ้นสามัญ) |
| `names` | ชื่อที่แสดงบนเว็บ (ไม่ใส่ก็ได้) |
| `benchmark` | ดัชนีที่ใช้เปรียบเทียบ ค่าเริ่มต้น `SPY` |
| `fundamentals` | `false` = ไม่ใช้ข้อมูลงบการเงิน (คะแนนจะใช้เฉพาะเทคนิคอล) |
| `site_url` | เว้นว่างได้ ระบบใช้ลิงก์ GitHub Pages ให้อัตโนมัติ |

ข้อควรรู้:
- รองรับเฉพาะ**หุ้นและ ETF ที่ซื้อขายในตลาดสหรัฐฯ** (NASDAQ, NYSE) ระบบใช้ปฏิทินวันทำการของตลาดสหรัฐฯ จึงใช้กับหุ้นไทย (.BK) ไม่ได้
- แนะนำไม่เกินประมาณ 30 ตัว เพื่อให้ข้อความ LINE อ่านง่ายและรันเร็ว
- การแก้ไฟล์นี้นับเป็น "กิจกรรม" ของ repo ด้วย ช่วยให้ GitHub ไม่ปิด schedule อัตโนมัติ

## 7. การสั่งรันเองหรือส่ง LINE ซ้ำ

1. ไปที่ repo → แท็บ **Actions** → **Daily snapshot** → ปุ่ม **Run workflow**
2. ถ้าต้องการให้ส่ง LINE ใหม่แม้วันนั้นส่งไปแล้ว ให้ติ๊ก **force_line**
3. กด **Run workflow** (สีเขียว)

ใช้ **Run workflow** เสมอ อย่ากด **Re-run** ที่รอบเก่า เพราะ Re-run จะใช้โค้ดเวอร์ชันเก่าของรอบนั้น

## 8. การตั้งค่าที่ใช้อยู่ (สำหรับอ้างอิง)

GitHub → **Settings → Secrets and variables → Actions**

| ชื่อ | ประเภท | ค่า |
|---|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | Secret | Channel access token (long-lived) จาก LINE Developers → แท็บ Messaging API |
| `LINE_USER_ID` | Secret | Your user ID (ขึ้นต้นด้วย `U`) จาก LINE Developers → แท็บ Basic settings |
| `SEC_USER_AGENT` | Variable | `StockMonitor/1.0 อีเมลของคุณ` |

และ **Settings → Pages → Source: GitHub Actions**

- **ห้ามแชร์ token** ให้ใคร ถ้ารั่วให้กด **Reissue** ใน LINE Developers แล้วอัปเดต secret ใน GitHub
- **Workflow "Keep schedules alive"** รันวันที่ 1 และ 20 ของทุกเดือน เพื่อไม่ให้ GitHub ปิดการรันอัตโนมัติ ไม่ต้องทำอะไร

## 9. ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ไม่มีข้อความ LINE วันนี้ | (1) วันหยุดตลาดสหรัฐฯ (2) GitHub รันช้า ให้รอรอบสำรอง 08:30 น. (3) ดูแท็บ Actions ว่ามีรอบไหน fail ไหม |
| Workflow fail: `LINE API 401` | Access token ผิดหรือหมดอายุ ให้ออก token ใหม่แล้วอัปเดต secret |
| Workflow fail: `LINE API 400 ... to ... invalid` | `LINE_USER_ID` ผิด หรือยังไม่ได้เพิ่ม Official Account เป็นเพื่อน หรือบล็อกไว้ |
| Workflow fail: `LINE API 429` | ส่งข้อความเกินโควตารายเดือนของ LINE (แผนฟรีเหลือพอสำหรับวันละ 1 ข้อความ) |
| Log มี `SEC_USER_AGENT not set` หรือ `SEC ... 403` | ยังไม่ได้ตั้ง Variable `SEC_USER_AGENT` ที่มีอีเมล คะแนนจะใช้เฉพาะเทคนิคอล |
| หุ้นบางตัวขึ้น STALE หรือ NO_DATA | Yahoo ยังไม่ปล่อยราคาปิดของวันนั้น หรือชื่อย่อหุ้นผิด ถ้าเป็นทุกวัน ให้ตรวจชื่อใน `snapshot.config.json` |
| หน้าเว็บขึ้น "No snapshot published yet" | ยังไม่เคยรันสำเร็จ ให้สั่ง Run workflow หนึ่งครั้ง |
| Workflow ขึ้นเตือน "GitHub Pages is not enabled" | ไปที่ Settings → Pages → Source: **GitHub Actions** |
| Workflow หยุดรันเอง | GitHub ปิด schedule เพราะ repo ไม่มีกิจกรรม 60 วัน ให้ไปที่ Actions → Daily snapshot → **Enable workflow** |
| คำเตือน Node.js 20 / Ubuntu 26 | เป็นแค่การแจ้งเตือนจาก GitHub ไม่มีผลต่อการทำงาน |

## 10. ข้อจำกัดของโหมดฟรี

- ข้อมูลเป็น**ราคาปิดรายวัน** ไม่ใช่ real-time และ Yahoo Finance เป็นแหล่งข้อมูลที่ไม่เป็นทางการ อาจมีข้อมูลช้าหรือผิดพลาดบ้าง
- หน้าเว็บ**เป็นสาธารณะ** ถ้า repo เป็น public ใครมีลิงก์ก็เห็นรายชื่อหุ้นของคุณ (ไม่มีข้อมูลพอร์ตหรือจำนวนเงิน)
- ไม่มีระบบล็อกอิน พอร์ตโฟลิโอ หรือการสั่งงานผ่าน LINE bot ฟีเจอร์เหล่านี้มีในแพลตฟอร์มเต็ม (ดู `PRODUCTION_DEPLOYMENT.md`)
